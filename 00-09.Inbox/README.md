# Inbox

This is the only folder in the vault where it's fine to be messy. Anything you're not sure how to file yet — a half-formed idea, a note dropped from your phone, a task you captured on the go — lands here first.

## How to use it

- Drop new, unsorted notes and files directly in this folder.
- On a regular cadence (daily or a few times a week), go through everything here and either:
  - move it into the right `10-19.Projects/`, `20-29.Areas/`, or `30-39.Resources/` file, or
  - decide it's not worth keeping and delete it.
- An empty inbox is the goal, not a permanent state — it should cycle through, not accumulate.

## Relationship to daily notes

Daily notes (`Daily_notes/YYYY-MM-DD.md`) serve a similar "quick capture" purpose for tasks and short notes tied to a specific day. Use this Inbox folder for anything that doesn't belong to a specific day — loose files, longer unsorted notes, or anything dropped in from outside Obsidian.
