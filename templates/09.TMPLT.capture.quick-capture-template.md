# Template: Quick Capture

> The smallest possible note: one loose thought, task, or idea, captured fast so it isn't lost, with no pressure to file it correctly right away. This is what the Inbox folder is for.

## What this template is for

Not every thought arrives conveniently inside a daily note or an existing project. Use Quick Capture for anything that shows up out of context — an idea on a walk, a task someone mentions in passing, a half-formed thought worth keeping — that you want to get down in under a minute, without stopping to decide where it belongs. Filing it correctly is a separate, later step (see "Notes on using this template" below).

## Required frontmatter fields

None required. A Quick Capture note is intentionally the lightest-weight file type in the system — frontmatter would add friction to the one note type that's supposed to have none. If you want to filter these later, a single tag in the body (like `#unsorted`) is enough.

## Required sections

There are no required sections — that's the point. Write the thought as plain text or a single task line. If it naturally grows into something with more structure while you're writing it, that's a sign it's actually a Project, Area, or Resource note in disguise — stop and file it as one of those instead.

## Notes on using this template

- **Speed over structure.** The only job of a Quick Capture note is to get the thought out of your head and onto disk before it's lost. Everything else — deciding if it's a task, a project seed, or nothing at all — happens later, during your regular Inbox pass (see `00-09.Inbox/README.md`).
- Name the file `YYYY-MM-DD-short-description.md` so a folder full of them still sorts chronologically and stays scannable.
- An Inbox note that's still sitting there unsorted after a couple of weeks is a signal, not a failure — either file it properly, or admit it wasn't actually important and delete it. A Quick Capture note is meant to be short-lived.
- If you're capturing a task that clearly belongs to an existing Project or Area, it's often just as fast to link it directly in your daily note's Intake section instead (see `AI_INSTRUCTIONS.md` § "Linking tasks to their project or area") — use whichever capture point you happen to have open at the moment.
