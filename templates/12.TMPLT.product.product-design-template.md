# Template: Product Design

> A `.PRODUCT.` note describes one specific thing you sell (or plan to sell) — separate from the `.PRJ.` note that tracks the work of building or launching it. Part of the **Business OS** module.

## What this template is for

A `.PRJ.` note answers "what am I doing this week to ship this?" — it's full of checkboxes and changes constantly. A `.PRODUCT.` note answers the much more stable question "what is this thing, who is it for, and what does it cost?" Separating the two means a product's positioning doesn't get lost in a project file's task churn, and a finished project's product note keeps being useful long after the project itself is archived.

## Required frontmatter fields

```yaml
---
Type: "Product"
Parent Brand: "[[<brand-file>]]"
Status: "Idea" | "In Development" | "Live" | "Retired"
---
```

## Required sections

1. `## What it is` — one or two sentences, plain language, no jargon — what does a buyer actually receive?
2. `## Who it's for` — the specific person with the specific problem this solves; "everyone" is not a valid answer here.
3. `## Value proposition` — why this, instead of doing nothing, or instead of the obvious free/DIY alternative?
4. `## Price` — current price (or price range if still being tested) and one line on how that number was reasoned, not just picked.
5. `## Notes` — anything else worth keeping: what changed since an earlier version, feedback patterns, ideas for a future version.

## Notes on using this template

- **A product note can exist before a project does.** An idea worth writing down as a `.PRODUCT.` note with `Status: "Idea"` doesn't need a `.PRJ.` note yet — see the ideas-inventory pattern (`20-29.Areas/21.active_areas/21.AREA.ideas-inventory.md`) for where ideas live before they're worth a full product write-up, and this template for once an idea is concrete enough to describe properly.
- Link the `.PRJ.` note that's building or launching this product back to this file (and vice versa) so either one is one click from the other.
- Update `Status` as it actually changes — a `.PRODUCT.` note stuck at `"Idea"` long after you've started selling it will mislead anything (a scoreboard, a dashboard query, an AI assistant) that reads that field to decide what's actually live.
