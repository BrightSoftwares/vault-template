# Template: Weekly Scoreboard

> A weekly scoreboard is a short, numbers-first companion to the base weekly review — not a replacement for it. Part of the **Steering Pack** module. Where the weekly review asks "what happened and what's next," the scoreboard asks one narrower question every week: "is this actually adding up to anything?"

## What this template is for

The base `.RESOURCE.` weekly review (`templates/05.TMPLT.review.weekly-review-template.md`) is qualitative by design, and that's correct for most weeks. But qualitative-only tracking makes it easy to feel busy for months without noticing that no Waypoint moved and no `Direct` project earned a customer. The scoreboard is a small, fast, numbers-first check-in that catches that — it should take under five minutes to fill in, every time. If it starts taking longer, you're overbuilding it.

## Required frontmatter fields

```yaml
---
Type: "Weekly Scoreboard"
Week: "<e.g. 2026-W04>"
---
```

## Required sections

1. `## Currency split` — a rough count or percentage of this week's business-related hours by currency (Money / Capital / Wellbeing — see `[[30-39.Resources/31.business-os/31.RESOURCE.three-currencies-and-revenue-gate-guide]]`). Doesn't need to be precise — the point is noticing the shape, not accounting to the minute.
2. `## Direct project status` — one line per active `Revenue Path: "Direct"` project: still pre-customer, or has it made its first/latest sale?
3. `## Waypoint progress` — one line per Waypoint currently being served (per `Serves::`, see the North Star template): closer, unchanged, or slipped this week?
4. `## One number that mattered` — a single figure worth remembering later (a sale count, an email list size, hours spent) — resist the urge to track everything; pick the one number this particular week's work should move.

## Worked example

`[[Weekly_reviews/2026-W04-scoreboard]]` — paired with the base weekly review for the same week, `[[Weekly_reviews/2026-W04]]`.

## Notes on using this template

- **Pair it with, don't replace, the base weekly review.** Fill in the qualitative weekly review first (wins, what's stuck, next week's focus), then this scoreboard as a five-minute numbers pass over the same week.
- Skipping a week is fine and honest — leaving a gap in the file names is more useful than backfilling numbers you don't actually remember.
- If `serves_mapping_report.py` (see `30-39.Resources/32.steering-pack/32.RESOURCE.north-star-waypoints-and-scoreboard-guide.md`) shows a Waypoint with zero linked projects, that's the scoreboard's `## Waypoint progress` line for it: "unchanged — nothing currently serving this."
